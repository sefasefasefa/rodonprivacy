Privacy Policy for Social Media Management Extension

This browser extension respects and protects the privacy of its users.

Data Collection: The extension does not sell, trade, or transfer personal user data to third parties.

Usage: Local storage and request handling are strictly used to authenticate and render dashboard metrics for the user's connected social panel.

Security: All user interactions and API calls are handled locally within the browser.

Contact: For any questions, please contact the developer through the official support channel.
